## What could not be computed reliably

### A true roster history

"Most-rostered players across owners" is published as **players acquired by the**
**most different owners**, which is a floor rather than the real figure. It is built
from transaction destinations, so it counts a player who was traded, claimed or
signed, and misses one who was drafted by an owner and simply kept. Closing the gap
needs a weekly roster for every team in every season, which is roughly 4,800 requests
and is not stored today. The column is labelled for what it actually measures.

### Transactions with nobody attached

246 transactions name no team on either side and so cannot be
credited to an owner:

- 243 commissioner actions, which is what that type looks like in the payload.
- 3 trades that name no players at all. The league allows trading draft picks, so
  that is the likely explanation, but nothing in the response says so and the report
  does not claim it. They are counted in the total on file and excluded from every
  per-owner figure.

### The 2011 undercount

- 2011, list index 93: Yahoo returns HTTP 400: the transaction references a player record it has deleted.
- 2011, list index 166: Yahoo returns HTTP 400: the transaction references a player record it has deleted.

Every transaction total for 2011 is short by exactly this many, and no workaround
exists: the records fail whether requested in a page or alone.

### Things the data cannot answer at all

- **Why anything happened.** No record here infers a motive, an injury or an intent.
- **Vetoed trades.** Yahoo keeps no record of a trade that was rejected, so the veto
  history has to be hand-entered. That is the Stage 7 curated wing.
- **Keeper tenure before 2015.** Keepers cannot be identified in the earlier seasons,
  so "longest-held keeper" cannot be computed and is also curated.

## Conventions worth knowing

- Consolation games never count, here or anywhere else in the record book.
- Streaks run across regular-season, championship and placement games in date order,
  and carry across seasons.
- A matchup where both sides took the same number of categories is a draw. It ends a
  run of either kind rather than extending one. There are 212 of them.
- "Missed the playoffs" is judged against that season's bracket, which was four teams
  in 2020 and six otherwise.
